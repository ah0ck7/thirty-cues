# Thirty Cues

Thirty lessons from nearly ten years on the Watermark Community Church production team, written for whoever sits in the producer’s chair next. Each lesson is rooted in the church’s vision, its 10 Markers, and the production team’s values, with a verse and a note on where it was learned.

Live site: https://ah0ck7.github.io/thirty-cues/

## What is here

- `index.html` is the whole site. It has no build step and no dependencies beyond two web fonts.
- `share.png` is the preview image shown when the link is shared.

To change the site, edit `index.html` and commit. GitHub Pages republishes it within a minute or two.
